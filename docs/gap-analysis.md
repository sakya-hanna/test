# ChatNotes 功能现状与缺口分析（2026-09-21）

> 范围：以"个人知识库"为目标形态盘点。现状 = feature/knowledge-search @ b58f0bb。
> 标注：✅ 已有 / 🟡 有但不完整 / ❌ 缺失。

## 1. 采集（输入侧）

| 能力 | 状态 | 说明 |
|---|---|---|
| ChatGPT 网页对话旁听 | ✅ | document-start 注入，SSE 旁听，轮次计数 |
| 增量采集（继续对话） | ✅ | 只发未归档的新增内容 |
| 匿名（未登录）采集 | 🟡 | 已实现被 revert，等复测后恢复 |
| 其他平台（Claude/Gemini/...） | ❌ | 协议层单平台硬编码 |
| 手动新建/粘贴笔记 | ❌ | 只能从对话生成，无自由入口 |
| 导入（Markdown/其他笔记应用） | ❌ | 无 |
| 采集失败提示与恢复 | ✅ | 状态栏如实提示 |

## 2. 整理（LLM 加工）

| 能力 | 状态 | 说明 |
|---|---|---|
| 对话 → Markdown 笔记 | ✅ | DashScope，检索式分类注入 |
| 分类自动归档 | 🟡 | LLM 给路径，但用户不能预设规则/纠正后学习 |
| 重新整理（用新 prompt 重跑同一快照） | ❌ | saved 后拒绝重复生成，没有"重新整理"入口 |
| 整理模板/自定义提示词 | ❌ | 提示词写死在代码里 |
| 追加整理（补充内容进已有笔记） | ❌ | 增量总结是"新内容→新笔记"，不能并入旧笔记 |
| 整理历史/版本 | ❌ | 覆盖即丢，无版本概念 |

## 3. 笔记管理（管理侧，当前最薄弱）

| 能力 | 状态 | 说明 |
|---|---|---|
| 浏览目录树/搜索 | ✅ | 混合检索（关键词+语义 RRF） |
| 查看笔记 | ✅ | Markdown 渲染只读 |
| **编辑笔记** | ❌ | 完全没有编辑入口，只能只读 |
| **删除笔记** | ❌ | 无删除（文件管理器去删），删后索引不自动更新 |
| **重命名/移动分类** | ❌ | 无 |
| 新建/重命名/删除分类文件夹 | ❌ | 无 |
| 回收站/误删保护 | ❌ | 删除即永久丢失 |
| 标签/收藏/置顶 | ❌ | 无 |
| 笔记与来源对话互跳 | 🟡 | 笔记尾部有会话 ID 文本，但不可点击跳转 |

## 4. 索引与检索一致性

| 能力 | 状态 | 说明 |
|---|---|---|
| 全文+语义混合搜索 | ✅ | FTS5 探测/LIKE 降级 |
| 笔记变更后索引自动更新 | 🟡 | ensureIndexed 按文件扫描；但外部删除/编辑（无 mtime 变化的内容校验）覆盖不全 |
| 删除笔记后向量/全文索引同步清理 | ❌ | SearchIndex.remove 存在但无 UI 触发路径 |
| 手动重建索引 | ✅ | 菜单入口（搜索/语义分开） |
| 索引状态可视化 | 🟡 | 搜索空结果时有提示，无独立状态页 |

## 优先级建议（按"管理闭环"补齐）

P0（没有它知识库不可维护）：编辑笔记、删除笔记（含索引/同步联动）、重命名/移动
P1（效率）：重新整理、笔记↔来源互跳、同步状态展示、服务器最小 Web 管理页
P2（体验）：回收站、标签收藏、导入、自定义整理模板、重新分类
P3（扩展）：RAG、多平台采集、PC 端、自动备份
